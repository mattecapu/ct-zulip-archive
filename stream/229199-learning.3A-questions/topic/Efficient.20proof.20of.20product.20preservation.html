El Mehdi Cherradi (Nov 26 2026 at 18:02):

Right Kan extension along {0,...,n+1}→{0,...,n}\{0,...,n+1\} \to \{0,...,n\}{0,...,n+1}→{0,...,n} (where n+1n+1n+1 is mapped to nnn) can be computed pointwise from binary (and unary) products. If FFF preserves those, it preserves such Kan extensions, hence it preserves Kan extensions along the composite {0,...,n+1}→{0,...,n}→...→{0} \{0,...,n+1\} \to \{0,...,n\} \to ... \to \{0\}{0,...,n+1}→{0,...,n}→...→{0}, i.e. finite products.

So, "build up limit of type X from iterated limits" can be mean that limit of type X is a right Kan extension along a (finite) composite of Kan extensions computed pointwise from limits in the class.

@El Mehdi Cherradi Your suggestion has helped me organise these ideas in my mind a little better! I was thinking about how to view this through the usual construction of limits from products and equalisers. What I've figured out is the following.

We start with a category J\mathcal{J}J. From this, we can make a "bipartite" category Bipartite(J)\text{Bipartite}(\mathcal{J})Bipartite(J) as follows. The collection of objects is Ob(J)∐Mor(J)\text{Ob}(\mathcal{J}) \coprod \text{Mor}(\mathcal{J})Ob(J)∐Mor(J). For each morphism f:j→j′f : j \to j'f:j→j′ in our original category, we add two morphisms to this new category - one from the object representing jjj to the object representing fff, and one from the object representing j′j'j′ to the object representing fff.

Then, there is an initial functor Bipartite(J)→J\text{Bipartite}(\mathcal{J}) \to \mathcal{J}Bipartite(J)→J which sends each object to itself and each morphism to its codomain. So to compute a limit of a diagram with shape J\mathcal{J}J, it suffices to compute the limit of the corresponding diagram with shape Bipartite(J)\text{Bipartite}(\mathcal{J})Bipartite(J).

Next, we have a functor Bipartite(J)→Eq\text{Bipartite}(\mathcal{J}) \to \text{Eq}Bipartite(J)→Eq, where Eq\text{Eq}Eq is the shape category used for equalisers. So long as our ambient category C\mathcal{C}C has products, we can pointwise right kan extend along this functor. This means it suffices to compute a limit of a diagram of shape Eq\text{Eq}Eq, an equaliser! Indeed, one can check that the pointwise right kan extension products a parallel pair with domain ∏j∈JD(j)\prod_{j \in \mathcal{J}} D(j)∏j∈J​D(j) and codomain ∏α∈mor(J)D(codα)\prod_{\alpha \in \text{mor}(\mathcal{J})} D(\text{cod} \alpha)∏α∈mor(J)​D(codα).

Finally, computing the limit of this equaliser is equivalent to right kan-extending along the canonical functor Eq→1\text{Eq} \to 1Eq→1.

So it seems that these various limit-reshaping operations fall into two types:
1) Restricting along an initial functor
2) (Pointwise) right kan-extending along another functor

The first type works in any category. If your category has limits of a certain shape, then you establish existence of such pointwise kan extensions and can then apply the second type. I believe this is a way to formalise making "iterated" limits to compute a larger limit?
