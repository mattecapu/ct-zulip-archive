Topic: Coequalizers in the Category of G-Spaces

Ruby Khondaker (she/her) (Jul 28 2026 at 14:37):

Let GGG be a topological group, and GTopG\mathbf{Top}GTop denote the category of GGG-spaces - meaning, topological spaces equipped with a continuous GGG-action. This is exactly the category of algebras for the monad G×(−)G \times (-)G×(−) on Top\mathbf{Top}Top, so the forgetful functor GTop→TopG \mathbf{Top} \to \mathbf{Top}GTop→Top creates all limits, and creates all colimits that the monad and its square preserve.

So GTopG\mathbf{Top}GTop is complete. Since products distribute over coproducts in Top\mathbf{Top}Top, it also has coproducts that are created by the forgetful functor to Top\mathbf{Top}Top. I was interested in understanding when it has coequalizers, and what they look like.

If GGG is locally compact (or core-compact, but this turns out to be equivalent for topological groups), G×(−)G \times (-)G×(−) preserves quotient maps. Hence GTopG\mathbf{Top}GTop in this case would be cocomplete and the forgetful functor creates coequalizers.

However, if GGG is not assumed to be locally compact, I think GTopG \mathbf{Top}GTop can still be argued to have coequalizers. Here is the approach I have in mind:

Let X,YX, YX,Y be GGG-spaces, and f,g:X→Yf, g : X \to Yf,g:X→Y be two GGG-equivariant maps. We can define a copresheaf F:GTop→SetF : G \mathbf{Top} \to \mathbf{Set}F:GTop→Set where F(Z)F(Z)F(Z) is defined to be the set of GGG-equivariant maps Y→ZY \to ZY→Z that coequalize f,gf, gf,g. We seek a representation of FFF, which is equivalently an initial object of ∫F\int F∫F, its category of elements.

Now, FFF preserves limits (indeed this is true in any category), so the projection π:∫F→GTop\pi : \int F \to G\mathbf{Top}π:∫F→GTop creates limits. Hence ∫F\int F∫F is complete.

It suffices to show that ∫F\int F∫F has a weakly initial set of objects. For this, I claim that the collection of objects (S,β)(S, \beta)(S,β) where SSS is a GGG-space whose underlying set is a subset of YYY suffices. This forms a set by standard arguments, and any equivariant map α:Y→Z\alpha : Y \to Zα:Y→Z can be factored as Y→α(Y)→ZY \to \alpha(Y) \to ZY→α(Y)→Z, whence α(Y)\alpha(Y)α(Y) is isomorphic to such an SSS and transport of structure can be used to define the requisite map Y→SY \to SY→S.

Of course, this is a rather involved construction - I don't really have any idea what coequalizers explicitly look like when GGG is non-locally-compact! Two questions:
1) Does this argument look correct?
2) I may have done some redundant work by redoing a variant of the standard adjoint functor theorem argument - is there a nice way to recast finding a coequaliser as some kind of adjoint such that this theorem can be applied?
