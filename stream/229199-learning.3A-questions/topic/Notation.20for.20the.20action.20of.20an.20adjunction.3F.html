Topic: Notation for the action of an adjunction?

Ignat Insarov (Nov 23 2026 at 07:42):

Alex Kreitzberg (Nov 23 2026 at 16:00):

There is only, so far - an entirely formal analogy between category theory and linear algebra/calculus that coend calculus notation exploits.

In this analogy, set valued functors are like real valued functions/vectors, homs are like the inner product, and therefore the yoneda lemma is like solving for a coefficient of an orthogonal basis, because representable functors are like the dirac delta function.

The adjoint and transpose terminology matches the terminology from linear algebra relative to this apparently formal analogy.

Ignat Insarov (Nov 23 2026 at 16:39):

@Ralph Sarkis  I do not know if I can explain my intuition but it would be my pleasure to try.

Let me denote arrow sets with the arrow notation, as customary in type theory. For example c→Cc′c →_\mathcal C c'c→C​c′ would be the set of all arrows in C\mathcal CC with source ccc and target c′c'c′. I am also going to provisionally call the function ∀cd.(F(d)→Cc)→(d→DG(c))∀ c d. (F (d) →_\mathcal C c) → (d →_\mathcal D G (c))∀cd.(F(d)→C​c)→(d→D​G(c)) that implements an adjunction F⊣GF ⊣ GF⊣G between categories C\mathcal CC and D\mathcal DD the FFF-GGG adjunct, and its inverse the GGG-FFF adjunct. I am also going to call the value of an adjunct at fff the adjunct image of fff.

Now let me wield this notation to explain my proposition that in the free-forgetful adjunction F⊣UF ⊣ UF⊣U the UUU-FFF adjunct implements multiplication of a matrix by a vector. The lollipop x⊸yx ⊸ yx⊸y will get a cameo appearance as the set of all linear maps from xxx to yyy, like in literature on linear logic.

  1. Let us have a function of type S→U(V)S → U (V)S→U(V). We can ask for its UUU-FFF adjunct image, which would be of type F(S)⊸VF (S) ⊸ VF(S)⊸V. But we are going to forget that the adjunct image is a linear map — with UUU as an intermediary we can treat it like a function. This UUU-modified UUU-FFF adjunct would have type (S→U(V))→(F(S)→V)(S → U (V)) → (F (S) → V)(S→U(V))→(F(S)→V).

  2. But S→U(V)S → U (V)S→U(V) is in one to one correspondence with the type of matrices with columns indexed by SSS — let us call it XXX. If we apply the (F(S)→_)(F (S) → \_)(F(S)→_)-(_×F(S))(\_ × F (S))(_×F(S)) adjunct (it comes from the Cartesian closed structure of functions between sets), we get X×F(S)→VX × F (S) → VX×F(S)→V.

  3. This X×F(S)→VX × F (S) → VX×F(S)→V type we now read as something that takes a matrix and a vector and computes a vector. May as well call it «multiplication». It does seem to be doing what one would expect from multiplication of a matrix by a vector.

In short, we apply an adjunct to the adjunct.

Ignat Insarov said:

Alright. I have seen this called «transpose» but I am confused why people call it so. It does not seem to have anything to do with transposition of matrices. If we take the free-forgetful adjunction of vector spaces to sets, the adjunct from functions to linear maps performs something I can best describe as multiplication of a matrix by a vector.

Adjunctions take their name from linear algebra, where two operators are adjoint when ⟨u,Tv⟩=⟨Su,v⟩\langle u, Tv \rangle = \langle Su, v \rangle⟨u,Tv⟩=⟨Su,v⟩. In particular for finite dimensional vector spaces, if T=A⋅−T= A \cdot -T=A⋅− is multiplication by a matrix, then S=AT⋅−S = A^T \cdot -S=AT⋅−. Hence the transpose.
