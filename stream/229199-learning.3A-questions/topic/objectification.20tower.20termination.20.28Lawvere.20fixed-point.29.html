Morgan Rogers (he/him) (Jul 28 2026 at 12:44):

@Giannis Karabesinis this is a strange definition, for the following reasons:

  1. the endomorphism ttt of YYY doesn't interact with the remaining structure. Perhaps you want to talk about YYY admitting a fixed-point-free endomorphism rather than including it in the structure?
  2. The subobject DDD of A′A'A′ is redundant. It seems to me that (A′,Y′,t′)(A',Y',t')(A′,Y′,t′) "objectifies" (A,Y,t)(A,Y,t)(A,Y,t) if and only if (point 1 holds and) there is a map A′×A→YA' \times A \to YA′×A→Y such that every g:A→Yg: A \to Yg:A→Y is of the form d(x,−)d(x,-)d(x,−).

Taking the above into account (so dropping the ttt), I think the claim "if ttt is fixed-point-free, then no LLL objectifies itself" should read "if YYY admits a fixed-point-free endomorphism, then L=(A,Y)L = (A,Y)L=(A,Y) does not objectify itself", with the proof indeed following from Lawvere's fixed point theorem. On the other hand, if YYY is a terminal object then (A,Y)(A,Y)(A,Y) objectifies itself for any AAA admitting a global element 1→A1 \to A1→A.

Morgan Rogers (he/him) (Jul 28 2026 at 12:51):

If you want a more interesting example of a "self-objectifying" pair, you need to dig up some categories where the endomorphisms of objects have interesting fixed points AND you need to be careful about what count as elements in expressions like d(x,−)d(x,-)d(x,−).

For instance, in the category of pointed sets, the two-element set 222 has exactly two endomorphisms, and the pair (2,2)(2,2)(2,2) "objectifies itself" if we consider the elements of these sets in the usual sense. BUT, these are not global elements in the categorical sense: a global element of XXX is a function 1→X1 \to X1→X, where 111 is the terminal object, but because we're in the category of pointed sets, the terminal object is the set with a unique element (which is also the distinguished element), and there is only distinguished-element-preserving function 1→21 \to 21→2 (or indeed to any set), so no function A×A→YA \times A \to YA×A→Y can be pointwise surjective in the sense you defined!
